Dynamic Table Form

Collect data in table format and sync with Google Sheets

Setup Instructions:

  1. Create a Google Apps Script project at script.google.com
  2. Copy the provided Apps Script code into your project
  3. Create a Google Sheet and get its ID from the URL
  4. Update the SHEET_ID in the script
  5. Deploy the script as a web app and paste the URL below
